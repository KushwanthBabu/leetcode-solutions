## Solution

```java
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false;
        }
        int original = x;
        int reversed = 0;
        while (original != 0) {
            int digit = original % 10;
            reversed = reversed * 10 + digit;
            original = original / 10;
        }
        return reversed == x;
    }
}
```
